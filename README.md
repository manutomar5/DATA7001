#  Rain Prediction in Australia - A Data Science Project

This project focuses on creating a machine learning model to predict whether it will rain the next day in Australia using historical weather data.

##  Objective

Using the dataset provided, the goal is to train classification models to accurately predict the **RainTomorrow** variable — answering the question:  
**Will it rain tomorrow?** (`Yes` or `No`)

##  Dataset Overview

- Contains **10 years of daily weather observations** from multiple locations across **Australia**.
- Target variable: **RainTomorrow**
  - Labeled `Yes` if the rainfall for the next day was **1mm or more**.
- Features include temperature, humidity, wind speed, atmospheric pressure, and more.

##  Project Scope

- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Model Training & Evaluation (e.g., Logistic Regression, Random Forest, XGBoost)
- Model Comparison
- Final Prediction and Results Interpretation
